# Made by CKT

A simple 3-page Astro site: home, about, support.

## Run it

```
npm install
npm run dev
```

Then open http://localhost:4321

## Where things live

| What                      | Where                                  |
| ------------------------- | --------------------------------------- |
| Colours, fonts, spacing   | `src/styles/global.css`                 |
| Header/footer/nav         | `src/layouts/Layout.astro`              |
| Home page                 | `src/pages/index.astro`                 |
| About page                | `src/pages/about.astro`                 |
| Support/contact page      | `src/pages/support.astro`               |
| Lottie animation JSON     | `public/lottie/ai.json`         |
| Lottie player component   | `src/components/LottieMark.astro`       |
